# Guia do quadro Trello — projeto individual

O PDF exige um **quadro público**, **captura de tela** e **link no README.md**.
Este documento é um planejamento para criar os cards manualmente; **não é
um comprovante de uso do Trello**.

## Colunas

- Backlog
- A Fazer
- Em Andamento
- Concluído

**Atenção:** atribua seu usuário aos cards e escreva critérios de aceite. 
Mova somente **um card por vez** para Em Andamento. Quando terminar,
mova-o para Concluído. Não apresente um print fabricado; tire uma captura
real do quadro final e publique em `docs/trello-final.png` ou similar.
